# 镜头、HUD与菜单过渡（本地版）

- 镜头zoom=0.72：人物和路面屏幕尺寸约为此前72%，可视世界约1111×833；窗口仍800×600，不是假装改窗口就是提高素材分辨率。
- 世界高度1000，适配更远镜头；人物保持40%水平目标位，偏置80/zoom。
- HUD左上320×96面板：HP100进度条；下面SCORE、TIME/s、DIST/6000三列，数字由无标签mode2 Monitor提供。
- HUD美术是SVG，生命条101个造型对应0..100。数字不再使用旧分散的带标签框。
- 生命health初始100；当前固定关卡无敌人/伤害陷阱，坠落保底逻辑扣25、归零结束，不再是3条命。
- 菜单改为透明面板，不再覆盖整幅旧背景；文字暂用英文避免SVG字体缺字。
- openMenu：冻结玩法 → 0.4秒逐步压暗至约72% → 0.4秒菜单淡入。closeMenu：0.32秒菜单淡出 → 0.4秒遮罩退去 → 恢复玩法。
- uiBusy锁过渡输入，避免连续ESC/重开触发多个动画竞争。
- 独立蓝色AABB框默认隐藏（debugLevel=false）。
- 验证：SVG/JSON校验、headless编译启动；实际视觉层级、数值居中及菜单渐变需要GUI验收。HUD与面板为相机跟随世界精灵，引擎相机平滑可能导致短暂偏移，尚非原生屏幕UI。
