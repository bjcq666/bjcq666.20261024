# 固定关卡（12000px）

## 规格

- 逻辑进度 0..12000，对应世界 `x = -6000..6000`。`map` 13600×1400，两侧各留 800 余量给相机与转场；视口 1528×1146（窗口 1100×825、`cameraZoom = 0.72`）。
- 16 块连续矩形地形，台面高度 `-208..-78`。跳跃初速 `vy=22`、重力 `1.2/tick`，峰值约 200px，单跳足够上台；空中可再按一次二段跳（`vy=20`）。
- 4 处坑洞：`(-3480,-3080)`、`(-200,120)`、`(3500,3900)`、`(5250,5600)`，坑底到 `-300`；人物 `y < -420` 判定坠亡。
- 4 组顶部障碍（可撞头）：`x` 区间 `(-4950,-4820)`、`(-2200,-2020)`、`(1050,1190)`、`(3400,3620)`；底面 `130/170/90/145`，顶面 `310`。上升中撞到底面会被挡下并清零垂直速度，不会穿模。
- 速度 14px/tick（50Hz ≈ 700px/s），纯跑完 12000px 约 17 秒，所以仍然必须跳过坑洞和顶障。
- `Ground.svg` 每 500px 一根刻度柱（高柱/矮柱交替），关卡末端 `x=6000` 有粉色终点旗与方框。

## 代码

- `main.spx`：地形与顶障矩形表、距离/计时、相机、流程与转场。矩形表是碰撞与图形的唯一真源。
- `Player.spx`：宽 28、高 114 的脚底锚点 AABB。先按 `vx` 做水平扫掠（侧壁贴边、不自动爬台），再按 `vy` 做垂直跨越判落地，最后在上升段做顶障夹取。
- `Ground.svg`：按上面的矩形表生成的可见地形、顶障块与刻度柱。**改表必须同步重生成图**，不能只改一边。
- `level-background.svg`：13600×1400 远景（深底 + 双层低透明度建筑），与 `map` 同尺寸，避免相机拉远时露白边。
- `DebugBox`：独立蓝色调试矩形，把 `main.spx` 的 `debugLevel` 设为 `true` 才显示，不参与碰撞。
- `Camera.setXYpos Player.xpos + 80 / cameraZoom, 0`：目标把人物放在视口水平 40% 处；引擎相机自带平滑，实测稳定在 42.7%（偏置 111px / 视口 1528px），运动中不是严格固定像素。

## 操作与测试

- `←`/`→` 移动，`↑`/空格跳跃、松开再按二段跳；`ESC` 暂停/继续，`Q` 暂停→主菜单，`R` 死亡/通关后重开，`M` 结算→主菜单。
- 到 12000px 触发通关结算；死亡或通关都会把舞台重置藏进黑罩之后（见 `docs/UI.md`）。
- `python3 scripts/test-level.py`：确定性 Python 镜像测试（地形连通、可通行、40% 相机目标）。它不是引擎端到端测试。
- headless 仅验证编译与启动；视觉必须 GUI 验收：起点、坑洞、顶障撞头、二段跳、暂停、死亡/通关转场、终点结算。

## 当前边界

- 原 `Coin.spx` / `Obstacle.spx` / `HUDPanel.spx` 仍保留但已不注册到场景（`onStart => { hide }`），不参与玩法。
- 平台都是自底部延伸的实心块，没有悬空平台；顶障是静态块，不会掉落。
- 关卡是固定数据驱动的，没有随机生成或程序化拼接。
