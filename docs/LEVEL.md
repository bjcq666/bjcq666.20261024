# 固定起伏关卡（本地开发版）

## 规格
- 逻辑进度0..6000px，对应SPX世界x=-3000..3000。800×600视口，世界7600×600，两侧留相机余量。
- 14块连续矩形地形，高度在-208..-88之间；台阶抬升50..100px，单跳足够越过。此版不放断崖，先验证台阶和镜头。
- 速度8px/0.02s，即约400px/s，不含起跳决策纯跑约15秒。
- 每500px调试柱，0/500/1000…6000均带矢量数字；1000px柱更高，终点粉色旗。
- 浅色低透明度建筑双层叠加，暂为静态远景，不宣称已实现视差。

## 代码
- main.spx：矩形表、计时、距离、相机和流程。
- Player.spx：宽28、高114的脚底锚点AABB；先水平侧壁扫掠，后向下跨越台面判落地；两次跳跃。
- Ground.svg：与上述矩形表对应的可见地形和标柱。改表后需要同步重生成图，不能单独改图。
- DebugBox：独立蓝色调试矩形，在main.spx将debugLevel设false可隐藏，不参与碰撞。
- Camera.setXYpos player.x+80,0：目标人物位于水平40%；引擎自带平滑，运动中不是严格固定像素位置。
- Monitor是屏幕坐标；菜单是世界精灵，显示时挪到Camera.xpos处。

## 操作与测试
- ←/→移动，↑/空格跳跃、松开再按二段跳；ESC暂停，Q回菜单。
- 到6000px通关（当前复用结束图并额外显示通关文字）；R重玩、M回菜单。
- HUD分数框改为距离/6000，仍显示本局时间和生命。
- `python3 scripts/test-level.py`：确定性Python镜像测试数据、墙面阻挡、支撑、自动跳台阶遍历和相机目标。它不是SPX引擎端到端测试。
- headless仅验证编译和启动；必须GUI验收：起点、每500px标柱、上台/下台、左右移动、二段跳、暂停回菜单、终点结算。

## 当前边界
- 原Coin/Obstacle代码仍保留，但不注册到场景，不应生成旧三角形或金币。
- 旧菜单静态图仍含历史文案/结束标题，后续重制。
- 平台都是从底部延伸的实心块，此版不含悬空平台、头顶碰撞或缺口。
- 当前关卡变更尚未推送；角色版本已推feature分支等待创建PR。
