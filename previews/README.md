# 火柴人动画本地预览

双击 `stickman-preview.html` 即可用浏览器离线播放，无需服务器或 Unity。

- 左：Idle 待机循环。
- 中：StartMove 起步一次，之后 Move 跑步循环。
- 右：Jump--1 至 Jump--40 连续源帧，30fps、约 1.33 秒循环；仅姿态动画，不模拟物理位移。修复原 Air 片段回放到旧帧、Land 重播旧帧，以及循环间隔错误重播落地动作的问题。循环末尾到开头仍有重播边界，最终游戏将按运动状态切换。
- 可暂停、重新播放、慢放、镜像、切换浅/深背景和青色剪影。
- 从用户提供的 TheRealGi 素材读取 `.anim` 的关键帧时间，通过 `.meta` GUID 定位 PNG。
- 保留完整原图画布统一缩至 480×270，未独立裁每帧、未改身体比例；70 张图嵌入 HTML，约 1.91 MiB。
- 尚未替换游戏人物，预览不代表落地锚点或动作衔接已完成调校。

## 重新生成（macOS）

```bash
python3 scripts/build-animation-preview.py "../Stickman Basic Pack"
```

转换仅使用 Python 标准库与 macOS 自带 sips，不修改原素材。不要手工编辑生成页，调整生成脚本后重新生成。
